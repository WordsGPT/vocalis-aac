# Vocalis Pocket TTS Spanish v3.3 browser weights

These INT8 ONNX files were exported from Kyutai's September 2026 Spanish
Pocket TTS voice-cloning checkpoint with the community Pocket TTS ONNX
exporter. They are used by Vocalis for on-device browser speech synthesis.

Source checkpoint: `kyutai/pocket-tts`, `languages/spanish/model.safetensors`,
revision `2dd944b099d06bb9edbd221fef138685711d9bf0`.

Exporter: https://github.com/lomotron/pocket-tts-onnx-export

Model license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Credit: Kyutai Pocket TTS authors. The source model's terms require consent
for voice cloning and prohibit deceptive or unauthorized uses; see
https://huggingface.co/kyutai/pocket-tts.

The tokenizer, BOS embedding, and bundle metadata are distributed with the
Vocalis app and must be kept at the matching v3.3 version.
